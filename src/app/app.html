Angular Aria listbox

Tab into a list, then use the arrow keys, Home, End, Enter or Space. None of these components contain key handling of their own except where the heading says so.

1. ngListbox on its own

2. The same list with focusMode="activedescendant"

3. A hand-written (keydown) handler on the same element

Press ArrowUp from the first row. The list wraps to the last row, the hand-written index clamps at the first, and the two highlights end up on different rows.

4. A hand-written (keydown) handler on a wrapper

It never sees the arrow keys, Home, End or any single character key, because the listbox calls stopPropagation() on them. Escape still gets through.
